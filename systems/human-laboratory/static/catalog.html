Structure is drawn with line, never with fill

.panel · .callout · .cols · .rule

There is no surface token. A panel is defined by its edge, because a fill measured 1.03:1 against this canvas and never rendered. Which line tier a boundary takes is decided by what the boundary means, not by taste.

A number states the reading; a chip states the state

.stat · .chip · .meter

A stat is three parts — .label says what is counted, .value is the number, .foot qualifies it. A number without a foot invites the wrong conclusion. A chip always carries its own word, so state never depends on colour alone.

Tabs work with the script stripped, because a radio is the state

.tabs · .tab-list · .tab-panel

Hidden radio inputs drive panel visibility in pure CSS. thl.interact.js upgrades the labels to a real ARIA tablist with arrow-key navigation, but it only moves focus and syncs attributes — the radio stays the single source of truth, so the enhanced and unenhanced pages cannot disagree. Six tabs is the ceiling; a seventh is a document that wants sections.

No script, no library, no build step — the whole mechanism is one radio group and six enumerated CSS rules. With thl.interact.js loaded the strip also answers to ← → Home End and reports itself to a screen reader as a tablist. Without it, the strip is a radio group, which is a worse experience but a working one.

In print every panel is revealed and separated by a rule. Paper has no tabs, and a document that loses two thirds of its content on the way to a PDF is a document that failed.

Tabs hide content. Never put a finding behind one. Put the alternate view of a finding behind one — the chart and the data table underneath it, the summary and the raw log, the result and the method.

If a reader has to open all the tabs to understand the section, the section wanted headings.

The pairing is positional: the nth radio shows the nth panel. Radios are direct children of .tabs, labels of .tab-list, panels of .tab-panels — the sibling selectors depend on it.

The long tail folds away; the sequence stays open

.accordion · .disclosure · .timeline

A disclosure is native <details> — it opens with the script stripped and its state belongs to the browser, not to us. Use it for evidence, method, and the full log: the material a reader needs to be able to reach but mostly will not.

METHOD // how the palette was validated
Every pair of series colours was measured, not just adjacent ones — adjacency in a token list is arbitrary and any two series can share a legend. Worst all-pairs CVD separation ΔE 9.8 under tritanopia; worst normal-vision ΔE 17.4.
EVIDENCE // why there is no fifth series
An exhaustive search over the usable hue range found no five-colour set that clears the floors while staying clear of the accent, warning and critical hues. A fifth category folds into the neutral --chart-other.
UNVERIFIED // what this catalogue does not prove
That the kit survives a real email client, and that the fonts bundle degrades cleanly on Windows. Both are asserted from the CSS, neither is measured.

A timeline is for a sequence where the interval carries meaning. If the gaps between entries say nothing, this is a list — use one.

Sortable, filterable, expandable — and still a table without script

.filter-bar · is-sortable · has-detail

Type to filter, click a header to sort, click a row to expand it. Sorting is numeric when a column's cells parse as numbers — otherwise "10" sorts before "9" and the table quietly lies. With the script absent every row reads, every detail stays visible, and the filter input is inert rather than broken.

This is what a tab is for. The figure shows the shape; the table gives the values to anyone who needs them — including a screen-reader user, for whom the aria-label alone would be a summary rather than the data.

Label the gridlines. A chart without a value axis is a picture of a trend, not a measurement.

Put the threshold where the data is not. A target label parked next to the final point collides with it at the one moment it matters.

Order bars by value, not by category name, unless the category order is itself the argument. The fold-in slot always sits last.

Sequential

Magnitude, not identity. One hue, monotone lightness — the reader ranks the steps without a legend.

Diverging

Polarity around a meaningful centre. The midpoint is a neutral grey and never a hue — a coloured middle invents a third category.

Sparkline

Shape at a glance, inside a sentence or a table cell. The endpoint is accented because the last value is the one being read.

A diagram earns its place by showing a mechanism

thl.diagram.css · four forms · +4KB

How something works, what depends on what, what is inside a boundary and what is outside it. If it restates a list, it is decoration — and a list is better. Four forms cover almost every document; each has a job, and using the wrong one is how a diagram ends up saying only that things are connected.

The scan line

The CRT motif. Decorative, so it is an empty element with nothing for a screen reader to announce, and it stops moving under prefers-reduced-motion. It needs a positioned parent.

Spend it once per document at most. It is the loudest thing the kit ships and it carries no information.
